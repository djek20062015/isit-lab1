# Ответы на контрольные вопросы

1. **DOM** — объектная модель документа. Элементы находятся через `getElementById`, `querySelector` и другие методы.
2. **Операции с DOM:** `createElement` создаёт строку, `remove` удаляет её, `textContent` меняет текст, `setAttribute` меняет атрибут, `classList.toggle` меняет класс.
3. **`textContent` и `innerHTML`:** первое вставляет текст буквально, второе интерпретирует HTML; для пользовательских строк безопаснее `textContent`.
4. **События:** `submit` формы, `click` кнопки, `change` фильтра, `input` поля. Обработчик — функция, вызванная при событии.
5. **`preventDefault()`** отменяет обычную отправку формы и перезагрузку страницы.
6. **Асинхронность:** ожидание ответа не блокирует интерфейс. `async` объявляет асинхронную функцию, `await` ждёт Promise.
7. **`response.ok`** нужен, потому что HTTP-ответы 404 и 500 не отклоняют Promise `fetch` автоматически.
8. **`try/catch/finally`:** основной код, обработка ошибки и обязательная очистка состояния соответственно.
9. **HTTP-коды:** 200 — успех, 404 — не найдено, 500 — внутренняя ошибка сервера; 201 — создано, 422 — ошибка валидации.
10. **Маршрутизация:** mock API сопоставляет метод и путь с ключами `ROUTES`. Для проекта добавлены `events`, `users` и маршруты создания, изменения, удаления мероприятий.
11. **Состояния:** загрузка, данные, пустой результат, ошибка.
12. **Проверка в браузере** повышает удобство, но пользователь может изменить клиентский код; реальный сервер обязан самостоятельно проверять входные данные и права.

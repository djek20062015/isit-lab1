# План проверки ЛР №5

Проверки необходимо выполнить вручную в браузере (F12 → Console). Ниже указаны **ожидаемые**, а не подтверждённые результаты.

| Сценарий | Действия | Ожидаемый результат |
|---|---|---|
| Обычная загрузка | Открыть страницу | Список из 7 мероприятий |
| Добавление | Заполнить форму и отправить | Создан черновик, список обновлён |
| Публикация | Нажать «Опубликовать» | Статус и счётчик обновлены |
| Удаление | Нажать «Удалить», подтвердить | Строка удалена, счётчик уменьшился |
| Медленный сервер | `MockApi.setDelay(2000,3000)` и обновить | «Загрузка…», кнопка недоступна |
| Ошибка сервера | `MockApi.setErrorRate(1)` и обновить | Красное сообщение с кодом 500 |
| Нет сети | `MockApi.setNetworkDown(true)` и обновить | Красное сообщение; после восстановления загрузка работает |
| 404 | Временно заменить `API` в `app.js` на `/api/eventss` | Красная ошибка 404; затем вернуть адрес |
| Пустой результат | Ввести несуществующее слово | Сообщение «Мероприятия не найдены», таблица скрыта, счётчик 0 |
| Неверная форма | Отправить пустое название | Подсказка под полем, запись не добавлена |
| Быстрый поиск | Быстро ввести разные строки | Показывается результат последнего поиска |

После тестирования: `MockApi.setDelay(300,800); MockApi.setErrorRate(0); MockApi.setNetworkDown(false);`.

## Скриншоты для сдачи

1. `images/01-loaded.png` — загруженный список.
2. `images/02-changed.png` — список после добавления, публикации или удаления.
3. `images/03-error.png` — красное сообщение об ошибке.

Скриншоты не включены в архив: они должны быть сделаны с реально открытой страницы после проверки.

# Лабораторная работа №5 — Реализация клиентской логики

**Предметная область:** система управления мероприятиями (EventManager).  
**Модуль:** Разработка web приложений.  
**Тема:** Современная разработка веб-приложений.

## Цель

Изучить обработку пользовательских событий, динамическое изменение DOM, асинхронные запросы `fetch()` и обновление интерфейса без перезагрузки страницы.

## Реализация

На основе ЛР №4 реализован экран организатора: каталог мероприятий, поиск по названию и площадке, фильтры по статусу и категории, форма создания мероприятия, изменение статуса публикации и удаление записей. В исходных данных семь мероприятий.

### События JavaScript

- `submit` — создание мероприятия после проверки названия, даты, площадки и вместимости; `preventDefault()` предотвращает перезагрузку.
- `click` — обновление списка, публикация/возврат в черновики, удаление с подтверждением.
- `change` — фильтрация по статусу и категории.
- `input` — поиск с задержкой 300 мс.

### Работа с DOM

`createEventRow()` создаёт элементы таблицы с помощью `document.createElement()`, `textContent`, `appendChild()`, `setAttribute()` и `classList`. `onDeleteClick()` удаляет строку через `remove()`. `onStatusClick()` меняет подпись, класс, атрибут `title` и счётчики. Данные пользователя вставляются через `textContent` для защиты от HTML-инъекций.

### Асинхронные запросы

`loadEvents()` использует `fetch()` и `URLSearchParams`; `apiRequest()` проверяет `response.ok`, разбирает JSON и сообщает код ошибки. `refreshList()` реализует `try/catch/finally`, состояния загрузки, ошибки, пустого результата и успешной загрузки. Для предотвращения устаревших ответов используется номер запроса.

**Важно:** исходный ZIP не содержал `js/mock-api.js`, `js/mock-data.js`, `js/app.js` и `css/styles.css`. Добавлена совместимая учебная реализация mock API; при наличии оригинального `mock-api.js` от преподавателя его можно использовать после проверки совместимости таблицы маршрутов.

## Запуск

Откройте `src/index.html` двойным щелчком в Chrome, Edge или Firefox. Никакой сервер и установка зависимостей не требуются. Данные mock API сохраняются только до обновления страницы.

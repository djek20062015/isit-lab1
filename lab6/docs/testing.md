# План проверки

Запуск: `cd lab6/src && php -S localhost:8000 -t public`.

| Запрос / сценарий | Ожидаемый код | Результат |
|---|---|---|
| GET `/` | 200 | Дашборд и карточки |
| GET `/events` | 200 | Семь мероприятий |
| GET `/events?status=published` | 200 | Только опубликованные |
| GET `/events/3` | 200 | Карточка с площадкой |
| GET `/events/999` | 404 | Страница 404 |
| GET `/events/create` | 200 | Форма |
| POST `/events` с `title=Да` | 422 | Ошибки полей, значения сохранены |
| POST `/events` с валидными полями | 302 → 200 | Новая запись в `storage/events.json` |
| GET `/venues` | 200 | Три площадки |
| GET `/venues/2` | 200 | Площадка и её мероприятия |
| GET `/nonexistent` | 404 | Страница 404 |
| POST `/venues` | 405 | Страница 405, заголовок Allow |
| GET `/tasks` и `/projects` | 404 | Старые адреса не работают |

Команды: `curl -i http://localhost:8000/events/999` и `curl -i -X POST -d 'title=Да' http://localhost:8000/events`.

**Восстановление тестовых данных:** при необходимости восстановить исходный `src/storage/events.json` из Git. Скриншоты главной, списка, карточки, формы с ошибками, страницы 404 и вкладки Network размещаются в `lab6/images/`.

Статусы в таблице — **ожидаемые**, фактические результаты следует отметить после локальной проверки на компьютере.
